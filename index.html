Kleur

Thuis via “KidsTube starten.cmd” werkt zoeken zonder sleutel. Op een website (zoals GitHub Pages) is een gratis sleutel nodig: console.cloud.google.com → YouTube Data API v3 → Inloggegevens. Beperk de sleutel tot jouw webadres.

Back-up en delen

Alles wordt alleen op dit apparaat bewaard (in de browser). Maak een back-up voordat je de browsergegevens wist. Met “videos.json maken” maak je het bestand dat je in je GitHub-repo zet, zodat alle apparaten dezelfde lijst krijgen.
